# Spec Delta

## Purpose
Добавить на клиенте возможность сравнения автомобилей из Featured каталога. Сравнение доступно только при выборе ровно двух автомобилей и показывает ключевые поля. Поведение существующего фильтра по бюджету сохраняется. Внешний backend/API не используется.

## ADDED Requirements

### Requirement: Выбор автомобиля
Система SHALL позволять пользователю выбирать автомобиль на карточке Featured с помощью управляющего элемента (чекбокс/переключатель).

#### Scenario: Выбор одного автомобиля
- WHEN пользователь отмечает автомобиль как выбранный
- THEN система SHALL отразить выбранное состояние для этой карточки и количество выбранных становится 1

### Requirement: Ограничение выбора до двух автомобилей
Система SHALL ограничивать количество одновременно выбранных автомобилей двумя; попытка выбрать более двух автомобилей не изменяет текущее состояние выбора.

#### Scenario: Попытка выбрать третий
- GIVEN уже выбраны 2 автомобиля
- WHEN пользователь пытается выбрать третий автомобиль
- THEN система SHALL отклонить действие и оставить выбранными те же 2 автомобиля (количество выбранных остаётся 2)

### Requirement: Снятие выбора
Пользователь SHALL иметь возможность убрать ранее выбранный автомобиль из сравнения.

#### Scenario: Удаление выбранного автомобиля
- GIVEN выбран как минимум 1 автомобиль
- WHEN пользователь снимает выбор у карточки автомобиля
- THEN система SHALL убрать этот автомобиль из набора выбранных и обновить количество выбранных

### Requirement: Отображение сравнения только при двух выбранных
Сравнение SHALL становиться доступным и отображаться только при ровно двух выбранных автомобилях; при 0 или 1 выбранном элементы сравнения скрыты.

#### Scenario: Два выбранных — сравнение видно
- GIVEN выбраны ровно 2 автомобиля
- WHEN пользователь открывает сравнение
- THEN система SHALL показать интерфейс сравнения

#### Scenario: Один выбранный — сравнение скрыто
- GIVEN выбран ровно 1 автомобиль
- THEN элементы интерфейса сравнения SHALL быть скрыты

### Requirement: Содержание сравнения
Интерфейс сравнения SHALL содержать для каждого из двух выбранных автомобилей: название (title), цену (JPY, форматированную), основные характеристики (meta/ключевые спецификации из карточки).

#### Scenario: Таблица сравнения
- GIVEN выбраны 2 автомобиля
- WHEN открыто сравнение
- THEN для каждого автомобиля SHALL отображаться его название, цена в JPY и основные характеристики

### Requirement: Сохранение существующего Featured budget filter
Существующий фильтр по бюджету SHALL сохранять текущее согласованное поведение раздела Featured.

#### Scenario: Фильтрация Featured
- WHEN пользователь применяет или сбрасывает фильтр бюджета
- THEN фильтр SHALL работать как и прежде, без изменения своей логики и без сетевых запросов

### Requirement: Отсутствие backend/API
Реализация SHALL выполняться полностью на клиенте на базе уже имеющегося списка Featured; сетевые запросы к backend/API в рамках сравнения не выполняются.

#### Scenario: Локальная реализация
- WHEN пользователь выбирает, убирает и сравнивает автомобили
- THEN все операции SHALL выполняться локально в браузере, без обращений к внешним сервисам
