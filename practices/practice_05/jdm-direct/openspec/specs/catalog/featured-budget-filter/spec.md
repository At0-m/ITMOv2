# catalog/featured-budget-filter Specification

## Purpose
Включить на клиенте фильтрацию раздела Featured JDM по максимальному бюджету в JPY. Фильтр показывает только те автомобили, у которых `priceJpy <= budget`. Порядок исходного списка сохраняется при отсутствии фильтра и после сброса. Внешний API/backend не используется.

## Requirements

### Requirement: Приём и разбор ввода бюджета
Система SHALL принимать необязательный ввод бюджета из UI: пустое или состоящее из пробелов значение означает отсутствие фильтра; непустое значение MUST быть конечным целым числом в диапазоне 1..100000000 JPY включительно.

#### Scenario: Нет фильтра (пустое/пробелы)
- **WHEN** пользователь отправляет форму с пустым или состоящим из пробелов значением
- **THEN** система SHALL показать все автомобили Featured в исходном порядке и ошибка отсутствует

#### Scenario: Валидное целое в диапазоне
- **WHEN** пользователь отправляет бюджет `4200000`
- **THEN** система SHALL трактовать его как валидный бюджет в JPY

### Requirement: Валидация невалидного непустого ввода
Система SHALL различать невалидные непустые значения и показывать понятную ошибку, не изменяя текущий отображаемый набор автомобилей.

#### Scenario: Не число
- **WHEN** пользователь отправляет `abcd`
- **THEN** система SHALL показать ошибку "Неверное значение бюджета" и текущие автомобили остаются без изменений

#### Scenario: Дробное число
- **WHEN** пользователь отправляет `4200000.5`
- **THEN** система SHALL показать ошибку "Дробные значения JPY не допускаются" и текущие автомобили остаются без изменений

#### Scenario: Неположительное значение
- **WHEN** пользователь отправляет `0` или `-1`
- **THEN** система SHALL показать ошибку "Допустимый диапазон: 1 — 100000000 JPY" и текущие автомобили остаются без изменений

#### Scenario: Выше максимума
- **WHEN** пользователь отправляет `100000001`
- **THEN** система SHALL показать ошибку "Допустимый диапазон: 1 — 100000000 JPY" и текущие автомобили остаются без изменений

### Requirement: Маппинг ошибок UI
Система SHALL отображать тексты ошибок согласно кодам валидации:

#### Scenario: Не число (nan)
- **WHEN** код ошибки `nan`
- **THEN** показывается сообщение "Неверное значение бюджета"

#### Scenario: Дробное (fraction)
- **WHEN** код ошибки `fraction`
- **THEN** показывается сообщение "Дробные значения JPY не допускаются"

#### Scenario: Неположительное (nonpositive)
- **WHEN** код ошибки `nonpositive`
- **THEN** показывается сообщение "Допустимый диапазон: 1 — 100000000 JPY"

#### Scenario: Слишком большое (too_large)
- **WHEN** код ошибки `too_large`
- **THEN** показывается сообщение "Допустимый диапазон: 1 — 100000000 JPY"

### Requirement: Инклюзивная фильтрация по priceJpy
Система SHALL включать только автомобили с `priceJpy <= budget` и исключать остальные; граница включительна.

#### Scenario: Граница включает Toyota Supra
- **WHEN** список содержит Toyota Supra A80 по цене 4_200_000 JPY и пользователь отправляет бюджет 4_200_000
- **THEN** Supra SHALL быть включена в результаты

#### Scenario: Граница исключает при 4_199_999
- **WHEN** пользователь отправляет бюджет 4_199_999
- **THEN** Supra SHALL быть исключена из результатов

### Requirement: Пустой результат и сброс
Система SHALL показывать пустое состояние при отсутствии совпадений и предоставлять действие "Сбросить фильтр", доступное при любом активном непустом валидном фильтре (включая отсутствие результатов), которое возвращает поведение по умолчанию.

#### Scenario: Пустой результат
- **WHEN** ни один автомобиль не удовлетворяет `priceJpy <= budget`
- **THEN** UI SHALL показать "По вашему бюджету ничего не найдено" и действие "Сбросить фильтр"

#### Scenario: Сброс
- **WHEN** пользователь нажимает "Сбросить фильтр"
- **THEN** поле ввода и ошибка очищаются, пустое состояние скрывается, все автомобили показываются в исходном порядке, а контрол "Сбросить фильтр" скрывается (фильтр больше не активен)

### Requirement: Отображение цены на карточке
Система SHALL отображать цену `priceJpy` для каждого автомобиля на карточке в Featured в формате `Intl.NumberFormat('ru-RU').format(priceJpy) + ' JPY'`.

#### Scenario: Цены видны на всех карточках
- **WHEN** отображается список автомобилей
- **THEN** каждая карточка содержит видимое значение цены вида "5 800 000 JPY" (локаль ru-RU)

### Requirement: Демонстрационные данные каталога и порядок
Система SHALL использовать демонстрационные данные каталога для Featured и сохранять их исходный порядок при отсутствии фильтра и после сброса.

#### Scenario: Исходный список и порядок
- **WHEN** фильтр отсутствует или был сброшен
- **THEN** отображаются автомобили в порядке: Nissan Skyline GT-R R34 (5_800_000), Toyota Supra A80 (4_200_000), Mazda RX-7 FD3S (3_100_000)
